# Jornal Escolar — Eletiva Comunicação da Palavra

Projeto em HTML + CSS + JavaScript para abrir diretamente no VS Code com Live Server.

## Estrutura
- index.html
- css/style.css
- js/script.js
- assets/cabecalho-comunicacao-da-palavra.png

## Como executar
1. Extraia o ZIP.
2. Abra a pasta no VS Code.
3. Abra `index.html`.
4. Clique com o botão direito e escolha **Open with Live Server**.
5. O jornal abrirá no navegador.

## Vídeos
Os botões de vídeo estão preparados com o Google Drive da Eletiva. Para usar links individuais:
- abra `index.html`;
- localize os três botões `Ver vídeos no Drive`;
- troque o `href` pelo link público de cada vídeo.

Importante: links de arquivos do Google Drive precisam ter permissão de visualização para o público-alvo. Se o vídeo estiver restrito, visitantes não conseguirão assistir.

## Identidade visual
A página usa as cores predominantes da arte enviada:
- Azul-marinho
- Azul
- Laranja
- Branco

A imagem enviada foi preservada em `assets/` e utilizada como cabeçalho do jornal.
